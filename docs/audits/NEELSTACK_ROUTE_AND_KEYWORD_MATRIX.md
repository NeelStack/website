## 3. Keyword Cannibalization Prevention
- **Rule 1:** `/services` acts as the directory hub; individual keywords (`custom software development company India`, `legacy application modernisation`) are targeted exclusively by their specific leaf pages (`/services/custom-software`, `/services/legacy-modernisation`).
- **Rule 2:** Matrix routes (`/services/[id]/for/[industryId]`) must target long-tail hybrid intents (e.g., `custom software development for healthcare India`, `AI development for education India`), ensuring they do not compete with the parent service page.
